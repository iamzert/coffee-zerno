# Кофейня «Зерно»

Учебный лендинг для портфолио: вымышленная кофейня.

**Сайт:** https://iamzert.github.io/coffee-zerno/

- Адаптивная вёрстка (телефон, планшет, компьютер)
- Меню с вкладками, которое строится из данных в JavaScript
- Форма бронирования с маской телефона и проверкой полей
- Анимации при прокрутке, доступность с клавиатуры

Сделано на чистых HTML, CSS и JavaScript без библиотек.
